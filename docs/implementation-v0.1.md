# 첫 구현 범위 — 로컬 학습 코어

2026-09-22. 사용자의 개발 계속 요청에 따라 기존 PRD의 독립 검증 가능한 부분부터 구현한다. 화면·모델 제품을 확정하거나 새 유료 서비스를 도입하는 결정은 포함하지 않는다.

## 이번 변경

- 순수 일정 함수: 오늘 시간 상한, 신규/복습 배정, 선행 조건, 미배정 보존, 휴식, 명시된 전체 시간 부족 표시.
- 로컬 기록: 이벤트 중복 방지, 계획 버전, 실제 수행/자기보고/미관측 구분, 오래된 피드백 보존과 적용 차단, 파일 재시작 후 복원.
- 반입 계약: PDF 변환 결과를 받을 페이지별 상태, 원본 해시·쪽수 추적, 검증 전 근거 사용 차단, 충실 MD 생성. PDF 자체를 읽는 변환기는 이번 범위 밖이다.
- 개발용 CLI: 합성 자료로 오늘 계획을 만들고 로컬 파일에 저장·복원한다. 학생용 최종 화면이 아니다.

Node.js 표준 모듈만 사용하며 외부 패키지를 추가하지 않는다. 설치와 인증 없이 합성 사례를 검증할 수 있고, 이후 화면·변환기·공식 계정 연결에서 같은 함수를 호출할 수 있게 한다.

## 구현·검증 순서

각 모듈은 실패하는 테스트를 먼저 작성하고 구현한다. 일정과 반입 계약은 별도 담당자가 병렬 구현하고, 기록·CLI를 통합한다. 모듈 테스트 뒤 새 프로세스에서 저장·복원·잘못된 입력을 검사한다. JavaScript 전문 검토에서 발견한 결함을 수정한 뒤 결과와 미검증 범위를 기록하고 GitHub에 반영한다.

## 제외와 한계

실제 PDF/OCR/LLM 변환, 학생 계정 로그인, 외부 전송, 백그라운드 알림, 자동 문항 생성·채점, 학생 화면·학습효과는 별도 단계다. 모듈 테스트 통과를 K01–K25 전체 통과나 실제 학생 사용 가능 상태로 표시하지 않는다. 일정은 일 단위 첫 구현이며 주간 최적화·개념 중복 병합은 구현 결과에 따라 남은 범위를 명시한다.
