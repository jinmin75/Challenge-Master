# Windows 설치파일 배포 조건

학생 제공 형태는 설치파일이다. v0.4 시험 설치본을 만들고 현재 개발 PC에서 설치·실행·제거했다. 학생 배포 완료 판단에는 아래 검증을 모두 적용한다.

1. 설치파일에 Node.js 실행 환경과 PDF 추출용 Python·pypdf를 포함해, 학생이 별도로 개발 도구를 설치하지 않고 실행한다. 대체 추출 엔진을 채택하면 이 항목과 검증 범위를 함께 바꾼다.
2. 학습 기록·검토한 PDF 추출본은 설치 폴더가 아닌 사용자 전용 데이터 폴더에 보관한다. 런처는 `CHALLENGE_MASTER_DATA_DIR`을 그 폴더로 지정한다. 원본 PDF는 읽기 전용으로 다루고, 제거 절차는 개인 기록을 동의 없이 삭제하지 않는다.
3. 학생용 화면은 로컬호스트에서만 열고, 기본 합성 데모를 실제 교재나 학생 진도로 오해하지 않게 표시한다. 배포본은 JSON 파일 작성 없이 자료·범위를 선택하는 흐름을 제공해야 한다.
4. Node.js·Python이 없는 깨끗한 Windows 환경에서 설치, 첫 실행, 텍스트 PDF 반입, 스캔 페이지 확인 필요 표시, 공부 기록 후 재시작, 주간 예측 갱신, 제거를 실제로 실행한다. **현재는 개발 PC의 시험 설치까지만 통과했다.** 깨끗한 PC 검증 전에는 일반 학생 배포 준비 완료로 표시하지 않는다.
5. 포함한 실행 환경과 패키지의 라이선스 고지, 배포본 서명 및 업데이트 방법을 빌드 시 확인한다.

현재 빌드는 Windows x64용 NSIS 설치파일이다. 앱 실행 환경은 설치 폴더에, PDF 원본·변환 초안·계획 기록은 `%LOCALAPPDATA%\ChallengeMaster`에 둔다. 처음 화면에서 학생이 PDF와 페이지 범위를 선택하고 추출 결과를 `needs_review`로 본다. 기존 자료를 교체하면 이전 기록을 보존하면서 새 계획으로 시작해야 하며, 변환 실패는 이전 설정을 바꾸지 않아야 한다. 설치파일은 [빌드 스크립트](../scripts/build-installer.mjs)로 만들고 [v0.4 실행 기록](verification-v0.4.md)에 검증 결과를 남긴다.

설치파일은 현재 서명되지 않았다. 업데이트는 같은 설치 경로의 재설치로 시험했으며, 자동 업데이트는 구현하지 않았다. 제거기는 개인 기록을 보존하지만, 제거할 때 기록 삭제 여부를 선택하는 화면은 아직 없다. 포함한 런타임의 라이선스는 설치본의 `THIRD_PARTY_NOTICES.md`와 각 런타임 폴더에 둔다. 스캔 OCR, LLM 계정 연결, 실제 학생 자료 검증도 현재 배포 범위로 주장하지 않는다.
