## v0.8 대비 변경

- **탭**: 오늘 계획 · 교재 · 학습실 · 오답노트 · 내 기록. 주소의 `#` 뒤 이름으로 바뀌어 뒤로 가기와 즐겨찾기가 된다.
- **교재(A-1)**: 등록한 PDF의 추출 글자를 쪽별로 보고 낱말을 찾는다.
- **학습실(A-2)**: 문제와 첫 답안 → 근거 쪽 고르기(8쪽까지) → 원문과 대조 → 수정 답안과 복습. 대조를 시작하면 문제·첫 답안·근거가 고정되고 근거 글자가 기록 안에 복사된다(쪽마다 20,000자까지). 다시 풀기는 새 기록을 만든다.
- **오답노트(A-3)**: 주된 원인(일곱 가지)을 고른 기록이 모이고, 학생이 고른 복습일에 그날 계획의 복습 몫 안으로 들어간다. 하루 공부 시간은 늘리지 않는다.
- **학습로그와 마무리(A-4)**: 모아의 로그 유형, 단추 일곱 개, 확인 상태, 기록마다 요약 하나.
- **개인 Wiki로 내보내기(A-5)**: 모아의 「위키 폴더로 보내기」와 같은 배치. Chrome·Edge는 폴더에 바로 쓰고, 모든 브라우저는 zip을 받는다.
- **내 AI에게 검토받기(B)**: 앱은 보내지 않는다. 동의(서비스·자료·목적·정책 판) 뒤 요청문을 복사해 학생의 AI에 붙여 넣고, 받은 답을 「AI 추정 · 공식 채점 아님」으로 저장한다. 학습로그 후보는 승인 전까지 로그가 아니다.
- **캘린더(C)**: 오늘 계획 오른쪽에 색·기호 요약, 전체 캘린더와 날짜 선택지는 팝업(열림 200ms·닫힘 140ms, 동작 줄이기면 즉시).
- 백업 파일에 학습실 기록·학습로그·AI 답·동의가 들어간다.

## 남은 검증

- 실제 Safari(macOS·iOS), Edge, Firefox, 휴대폰·태블릿: **NOT RUN**. WebKit 시험은 Playwright의 WebKit 빌드로 했으며 Safari 자체가 아니다.
- 소비자용 AI 채팅 화면(chatgpt.com·claude.ai·gemini.google.com)에 실제로 붙여 넣고 답을 복사해 오는 흐름: **NOT RUN**. 모델은 CLI·에이전트로 불렀고 모델당 요청 한 번씩이다.
- 실제 폴더 고르기 창에서 Wiki 폴더에 쓰기, Finder에서 zip 두 번 눌러 풀기: **NOT RUN**(쓰기 코드는 브라우저 전용 폴더로 시험).
- 화면 읽기 프로그램으로 캘린더 요약·팝업 사용: **NOT RUN**.
- 학습 기능의 학습 효과, 여러 달 사용, 실제 교재 PDF, 학생 사용성: **NOT RUN**.
- 설치판(0.7.0)은 이번 변경 뒤 다시 빌드하지 않았다. 설치판 가이드 두 벌의 캘린더 절은 새 팝업 화면과 다르다(설치판은 예비이며 배포하지 않음).

K01–K25의 제품 전체 시나리오 통과를 이 기록으로 주장하지 않는다.
