# 향후 공적 시험 서비스 확장 — 보류

2026-09-22. 현재 KNUE 임용 준비 범위에서 분리했다. 저장 대상은 사용자가 지정한 [Challenge-Master](https://github.com/jinmin75/Challenge-Master)다. 현재 임용 준비 설계와 함께 보관하되 확장 기능 구현은 보류한다. 실제 업로드 여부는 저장소 커밋으로 확인한다.

## 다시 검토할 항목

- 다른 공적 시험의 범위·일정·응답 형식·루브릭을 교체할 수 있는 자료 계약.
- 기관별 자료 이용권, 공유 학습팩, 멀티테넌트 격리와 운영 책임.
- 개인 계정 도구 배포와 중앙 서버 서비스의 인증·비용·지원 범위 차이.
- QTI 등 교환 형식, 객관식·서술형·구술·실기·영상 과업의 차이.
- 사용성·학습효과·운영 원가·구매 의사를 실제로 관찰한 뒤 출시 판단.
- 작은 시험팩 장착 성공과 대규모 운영·교육적 타당성 검증을 분리.

## GitHub 저장 경계

- 저장 범위는 현재 임용 준비 설계, 검증 명세, 결정 기록, 확장 기획과 향후 비식별 코드·합성 테스트다.
- 학생 자료, 수험서 원문, 답안, 개인 볼트, 인증정보는 포함하지 않는다.
- 기존 개인 볼트와 별도 저장소로 관리한다. 전체 볼트를 커밋·푸시하지 않는다.
- 지정 저장소는 2026-09-22 확인 당시 공개 저장소다. 허용한 프로젝트 파일만 커밋하며 학생별 실제 자료는 공개 범위에 포함하지 않는다.
