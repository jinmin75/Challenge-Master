# Windows 시범 설치본 v0.5 검증 기록

검증일: `2026-09-27`. 대상은 합성 PDF와 이 개발 PC에 설치한 Windows x64 시범 설치본이다. 학생 교재·계정은 사용하지 않았다.

최종 산출물: `dist/Challenge-Master-Setup-0.5.0-win-x64.exe` (34,698,788바이트). SHA-256 `8a3da84ad60fd8d12060ab5187c62f9c8a864f07dd907e79f39769fb4d108b70`. 같은 디렉터리의 `.exe.sha256` 파일에도 기록했다.

## v0.4 대비 변경

- 제거기에 **개인 학습 기록·PDF 사본도 삭제** 선택 칸을 추가했다. 기본값은 선택 안 함(기록 보존)이다. 무인 제거는 `/DELETEDATA`를 줄 때만 기록을 지운다.
- 앱이 실행 중이면 제거기가 아무것도 지우지 않고 종료 안내를 띄운 뒤 종료 코드 3으로 멈춘다. 실행 중인 `node.exe`에 쓰기 열기가 실패하는지로 판단한다.
- 버전 표기를 `package.json` 한 곳에서 읽어 설치파일 이름·등록 정보에 넣는다.
- 빌드가 Git Bash의 GNU tar 대신 `System32\tar.exe`를 쓰도록 고정했다. GNU tar는 `H:\...` 경로를 원격 호스트로 해석해 빌드가 실패했다.
- 깨끗한 Windows 시험용 `npm run test:sandbox`(`scripts/run-sandbox.mjs`, `scripts/sandbox-run.ps1`)를 추가했다. Windows 샌드박스 명령줄 도구 `wsb`가 필요하다.
- 주간 예측 웹 테스트 2건이 `2026-09-23` 고정 날짜를 써서 날짜가 지나면 실패했다. 앱은 오늘 이전 날짜를 예측에서 빼는 것이 의도된 동작이므로, 테스트가 실행일 기준 오늘·내일을 쓰도록 고쳤다.

## 깨끗한 Windows 샌드박스 시험 (L16)

실행일 `2026-09-27`, `npm run test:sandbox`. 대상은 위와 같은 설치파일이다. 샌드박스는 Windows 11 Enterprise 10.0.26100, 한국어(OSLanguage 1042), 사용자 `WDAGUtilityAccount`였다. 시작 시점에 PATH에 `node`·`python`이 없었고, 루프백·링크 로컬 외 IPv4 주소가 없어 네트워크가 끊긴 상태였다.

| 단계 | 결과 |
|---|---|
| 기록 보존 흐름 | 기본 경로(`%LOCALAPPDATA%`의 `Programs` 아래) 무인 설치 종료 코드 0 → 번들 pypdf 6.17.0 → 합성 PDF 1쪽 반입 → 5분 기록 → 재시작 후 5분 유지·주간 예측 제공 → 시작 메뉴 바로가기 확인 → 실행 중 제거 거부 → 제거 후 설치 폴더·바로가기·등록 정보 삭제, 기록 보존. 통과 |
| 기록 삭제 흐름 | 같은 과정을 기본 데이터 폴더로 반복한 뒤 `/DELETEDATA` 제거 → 기록 폴더 삭제 확인. 통과 |

샌드박스의 스마트 앱 컨트롤 레지스트리 값은 2였다. 이 시험은 인터넷 표시가 없는 공유 폴더 파일을 무인 설치했으므로, 스마트 앱 컨트롤이나 SmartScreen이 학생 PC에서 어떻게 동작하는지에 대한 근거가 아니다.

시험 도구를 만드는 과정에서 두 가지를 고쳤다. 첫째, `.wsb` 설정 파일을 `WindowsSandbox.exe`로 여는 방식은 이 PC(빌드 26200, wsb 0.8.107.0)에서 샌드박스는 띄웠지만 폴더 연결과 로그온 명령을 하나도 적용하지 않았다. 그래서 `wsb start/connect/share/exec` 명령으로 단계를 직접 진행하게 바꿨다. `wsb start`만으로는 사용자 세션이 없어 `wsb connect`로 창을 연결해야 한다. 둘째, 시험 스크립트를 설치된 `node.exe`로 직접 돌리면 제거기가 앱 실행 중으로 올바르게 판단해 제거를 거부했다. 지금은 `node.exe` 사본으로 시험을 돌린다.

## 남은 검증

- 제거 화면의 선택 칸을 눈으로 확인하는 시험: **NOT RUN**. 무인 모드 세 경우만 자동으로 확인했다.
- 코드 서명: **없음**(D016에 따라 시범판은 서명하지 않음). 스마트 앱 컨트롤이 켜진 PC에서의 차단 여부는 실제로 시험하지 않았다.
- 깨끗한 환경에서의 스캔 쪽 표시, 화면 조작, 제거 후 재설치 시 기록 복원: **NOT RUN**.
- 스캔 OCR, 복잡한 표·수식, 실제 교재 충실도, 학생 사용성, LLM 계정 연결·학습효과: **NOT RUN**.

K01–K25의 제품 전체 시나리오 통과를 이 기록으로 주장하지 않는다.
