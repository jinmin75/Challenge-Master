# KNUE 개인 학습 가이드 v4.2 검증 계약

기준일 `2026-09-27`. [현재 PRD](prd.md)의 구현을 위한 계약. 아래 K01–K25의 제품 전체 시나리오는 아직 NOT RUN이다. 로컬 코어 v0.2까지의 근거는 [기존 검증 기록](verification-v0.2.md), 합성 PDF·주간 예측·로컬 화면의 근거는 [v0.3 검증 기록](verification-v0.3.md), 설치본의 근거는 [v0.4](verification-v0.4.md)·[v0.5](verification-v0.5.md) 검증 기록에 구분해 둔다. 합성 자료 테스트를 실제 학생 자료·계정·설치파일 검증으로 세지 않는다. 숫자는 초기 정책값이며 임용 합격에 최적화됐다는 실증 주장이 아니다.

## 정책 검증 방법

1. 합성 달력과 과업으로 정상 진행·이틀 지연·장기 공백·시험 임박·모든 선행관계 차단을 재현한다. 각 날짜의 시간 상한, 신규/복습 예산, 미해결 범위 보존을 검사한다.
2. 활동·자기보고·시험형 수행 이벤트를 구분하여 같은 기록을 반복 입력해도 숙달·복습 과제가 중복 증가하지 않는지 검사한다.
3. 초급·회독 중·종이교재 중심 세 흐름에서 '시작부터 다음 날 복귀'를 설명 없이 수행해 본다. 실패를 모두 남기며, 단순 클릭 감소만으로 효과라고 결론내리지 않는다.
4. 외부 모델 없이 시간·권한·저장 테스트를 먼저 수행한다. 그다음 사용자가 선택한 실제 계정·기기 한 조합에서 로그인을 포함한 연결을 확인한다.
5. 교재 근거를 확인한 연습 과제와 별도 새 과제로 피드백 오류·반복 오류·지연 수행·소요시간을 관찰한다. LLM끼리의 일치율을 정답률로 대체하지 않는다.

## 성공 기준의 단계 구분

- 기술 완료: K01–K25 및 저장·삭제·권한 회귀의 실제 통과. 현재 일부 모듈만 검증했으며 제품 전체 시나리오는 미실행.
- 현장 적용 판단: 학생의 동의 범위 내 소규모 사용에서 과도한 재촉, 재계획 요구, 자료 오류, 계정 중단과 이탈을 기록하고 수정. 임의의 9.8점으로 대체하지 않음.
- 합격 준비 개선: 고정한 시험 요구 범위에서 지연·제한시간 수행 변화를 관찰. 변화가 가이드 때문이라는 인과 주장은 별도 비교 설계가 필요함.
- 최종 목표: 실제 임용 결과를 자발적 제공 범위에서 확인. 합격·불합격만으로 개인의 학습 원인이나 서비스 인과효과를 단정하지 않음.
