## v0.6.2 대비 변경

- **학습 캘린더**(`web/calendar.js`, `src/calendar.mjs`): 한 달을 날짜별로 보여 준다. 지난 날은 기록 있음(확인 분 / 그날 첫 계획의 배정 분), 휴식, 확인 필요, 누락 확인, 사후 기록 중 하나이고, 앞으로의 날은 주간 예측의 예정 분과 보완 예정 분을 표시한다. 캘린더를 열면 확인이 필요한 가장 최근 날이 선택된다.
- **학생의 날짜 확인**: 확인 필요한 날에 ① 사후 기록(과업·분), ② 누락 확인(보완 계획을 함께 잡거나 누락 확인만), ③ 휴식 중 하나를 고른다. 새 기록 종류는 `day_reviewed`, `late_progress_recorded`, `makeup_scheduled` 세 가지이며 기존 기록은 고치지 않는다. 한 날짜의 확인은 한 번뿐이고 되돌리는 기능은 없다.
- **사후 기록의 반영(D020)**: 사후 기록 분은 재계획과 주간 예측에서 같은 날 기록과 똑같이 남은 분량에서 뺀다. 한 과업에 인정된 분(당일 기록 + 사후 기록)의 합은 그 과업이 처음 계획에 들어갈 때의 분량을 넘을 수 없다. 이 상한은 당일 기록에도 새로 적용된다.
- **보완 계획(D020)**: 내일 이후 날짜에 더할 분을 고른다. 한 날짜에 더하는 보완 분의 합은 하루 공부 시간 이하다. 보완 분은 그날의 계획과 주간 예측의 가용 시간에 더해진다.
- **월간 점검**: 기록한 날·휴식·확인 필요·누락 확인 일수와 사후 기록·보완 예정 분, 배정 대비 확인 분을 따로 보여 준다. 하나의 점수로 합치지 않는다. 점검 신호 초기값은 확인 필요·누락 2일 연속, 복습 과업 3일 초과 잔류, 미배정 범위다.
- 캘린더 기록은 지역 시차가 붙은 시각(`+09:00` 등)으로만 저장한다. UTC(`Z`) 시각이면 날짜 부분이 학생의 날짜와 어긋날 수 있어 거부한다. 등록 전 날짜에 대한 확인·사후 기록은 HTTP 층에서 거부한다(저장소는 등록일을 모른다).
- 설치본 시험(`smoke-app.mjs`)이 설치된 앱의 `calendar.js` 제공과 복원 기록 기준 오늘 칸 계산을 확인한다. Windows·Mac 설치본 시험이 같은 루틴을 쓴다.
- 개발 PC 설치 시험을 `scripts/smoke-local-install.mjs`로 묶었다. 시험 설치는 실제 설치와 같은 등록 정보·바로가기를 덮어쓰므로, 이 사용자에게 실제 설치가 있으면 아무것도 바꾸지 않고 멈춘다.

커밋 `595ea71`의 첫 CI 실행에서 Apple Silicon 시험이 한 번 실패했다. `open`으로 연 앱의 서버가 30초 안에 뜨지 않았다. 같은 실행을 다시 돌리자 통과했고, 캘린더 변경은 시작 경로를 건드리지 않는다. 서명 없는 앱을 처음 열 때 macOS 검사로 늦어질 수 있다고 추정해 대기를 90초로 늘렸다(원인은 `확인 필요`). 학생 Mac에서 첫 실행이 늦을 수 있다는 점은 첫 Mac 참여자 관찰 때 함께 본다.

화면 확인 중 테스트 데이터로 배정보다 많은 분을 기록하려다 서버가 거부해 화면이 비어 보인 일이 있었다. 앱 결함이 아니었다. 기록 칸의 최댓값 제한 때문에 실제 화면에서는 전송 전에 막힌다.

## 학생 가이드

두 가이드에 10절 「지난 날 확인하기 (학습 캘린더)」를 넣고 뒤 절 번호와 절 참조를 하나씩 밀었다. 화면 네 장은 `docs/pilot/guide/tools/shots-calendar.mjs`로 합성 기록을 만들어 찍었다. 단추 이름과 오류 문구는 0.7.0 화면 코드에서 그대로 옮겼다. PDF는 Windows 14쪽, Mac 13쪽이다.

## 남은 검증

- 설치된 0.7.0 앱을 실제 브라우저로 조작하는 시험: **NOT RUN**. 브라우저 시험은 저장소의 서버로 돌았고, 설치본 시험은 Node로 요청을 보낸다.
- 여러 달에 걸친 실제 사용, 달이 바뀌는 날의 표시: 합성 시험의 날짜가 실행일 기준이라 월 경계는 실행일에 따라서만 지나간다. **NOT RUN**.
- 점검 신호의 초기값(2일·3일·15분)이 학생에게 적절한지: 시범 관찰 뒤 조정.
- 되돌리기가 없는 확인을 학생이 잘못 눌렀을 때의 복구 절차: 없음. 시범에서 실제로 필요한지 관찰한다.
- v0.6 기록의 남은 항목(실제 Mac 첫 허용, macOS 13.5~14, 학생 PC의 Windows 경고, 스캔 OCR, 실제 교재, 학생 사용성, LLM 연결): **NOT RUN**.

K01–K25의 제품 전체 시나리오 통과를 이 기록으로 주장하지 않는다.
