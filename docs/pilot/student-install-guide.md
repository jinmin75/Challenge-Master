# Challenge Master 설치·사용·제거 안내 (시범판 v0.5)

Challenge Master는 직접 적은 공부 범위와 공부 시간으로 오늘 계획과 이번 주 예측을 만드는 Windows 프로그램입니다. 등록한 PDF는 사본과 추출 초안으로 함께 보관됩니다. 모든 기록은 이 PC 안에만 저장되며 인터넷으로 전송되지 않습니다.

> [!note] 시범판 안내
> 이 설치파일은 시범판이며 코드 서명이 없습니다. 따라서 파일을 받거나 설치할 때 Windows와 브라우저의 경고가 나타날 수 있습니다. 설치파일은 운영자에게 직접 받은 것만 사용하십시오.

## 1. 설치 전 확인

- 확인된 환경은 **Windows 11 x64(Intel·AMD 프로세서)**입니다. Windows 10, ARM 프로세서(Snapdragon 등) PC, S 모드 PC에서의 동작은 확인되지 않았습니다.
- 별도의 Node.js나 Python 설치는 필요하지 않습니다.
- **스마트 앱 컨트롤** 상태를 확인합니다. 확인 위치: `Windows 보안` → `앱 및 브라우저 컨트롤` → `스마트 앱 컨트롤 설정`(메뉴 이름 `확인 필요`). 상태가 **켜짐** 또는 **평가**이면 설치하지 말고 표시된 상태를 운영자에게 알리십시오. 이 설정을 끄는 것은 시범 참여 조건이 아닙니다.

## 2. 설치파일 받기

운영자가 정한 전달 경로(`운영자 기입`)로 `Challenge-Master-Setup-0.5.0-win-x64.exe`를 받습니다. 브라우저가 다운로드를 경고하거나 보류하면 그 화면을 캡처해 운영자에게 보내고 진행을 멈추십시오(경고 문구 `확인 필요`).

## 3. 설치

1. 받은 파일을 두 번 누릅니다.
2. 파란색 경고 창(`Windows의 PC 보호`)이 나타나면 `추가 정보`를 누른 뒤 `실행`을 누릅니다(창과 단추 이름 `확인 필요`). 이 단추가 없거나 설치가 차단되면 진행을 멈추고 화면을 캡처해 운영자에게 보내십시오.
3. 설치 마법사에서 설치 폴더는 기본값을 그대로 둡니다. `다음` → `설치` → `마침` 순서로 진행합니다(단추 이름 `확인 필요`).
4. 관리자 권한은 필요하지 않습니다. 프로그램은 현재 Windows 사용자 계정에만 설치됩니다.

## 4. 처음 사용하기

1. 시작 단추를 누르고 `Challenge Master`를 입력해 검색하거나, **모든 앱** 목록의 `Challenge Master` 폴더에서 엽니다(메뉴 이름 `확인 필요`). 창 없이 실행되므로 브라우저가 열리기까지 몇 초 동안 아무 표시가 없을 수 있습니다.
2. 기본 웹 브라우저에 프로그램 화면이 열립니다. 주소창의 주소는 `127.0.0.1`로 시작하며, 이 PC 안에서만 동작합니다. 주소의 숫자는 실행할 때마다 바뀌므로 즐겨찾기에 저장하지 말고 항상 시작 메뉴에서 여십시오.
3. **내 PDF로 공부 계획 만들기**에서 다음을 입력합니다.
   - **학습 PDF**: 본인이 이용 권한을 가진 PDF 파일. 32MB가 넘는 파일은 등록되지 않습니다.
   - **자료 제목**
   - **공부 범위**: 한 줄에 하나씩 `공부할 일 | 예상 시간(분) | 새 내용 또는 복습` 형식으로 적습니다. 예: `2장 핵심 개념 | 40 | 새 내용`. 최대 30줄입니다.
   - **하루 공부 시간**, **이번 주 공부 시간**(분 단위)
   - **시작 페이지**, **끝 페이지**: 글자를 뽑아낼 범위입니다. 책에 인쇄된 쪽 번호가 아니라 PDF 뷰어에 표시되는 쪽 순서를 기준으로 하며, 한 번에 30쪽까지 가능합니다. 기본값(1~1쪽)을 그대로 두면 1쪽만 처리됩니다.
4. **이 설정으로 시작**을 누릅니다.
5. 화면 위쪽의 **오늘 시작**을 누릅니다. **오늘 배정**에 오늘 공부할 일이 나타납니다. 이 단계를 거쳐야 시간을 기록할 수 있습니다.

> [!warning] 설정을 다시 등록할 때
> **이 설정으로 시작**을 다시 누르면 지금까지의 계획 기록은 보관 파일로 옮겨지고, 새 계획은 0분에서 시작합니다. 자료나 공부 범위를 바꿀 때만 다시 등록하십시오.

## 5. 매일 사용하기

1. **실제 공부 시간 기록**에서 **과업**을 고르고, **실제 공부한 분**을 입력한 뒤 **기록**을 누릅니다. 배정된 시간보다 큰 값은 입력되지 않습니다. 기록한 시간만 다음 계획에 반영됩니다.
2. 계획보다 시간이 부족하면 **오늘 가능한 시간 줄이기**에 남은 시간을 넣고 **다시 배정**을 누릅니다. 공부하지 않는 날에는 **오늘 쉬기**를 누릅니다.
3. 다음 날 프로그램을 열면 **남은 과업 다시 배정**을 눌러 그날 계획을 만듭니다.
4. 다 쓰면 화면 위쪽의 **앱 종료**를 누르고, `창을 닫아 주세요`가 표시되면 브라우저 탭을 닫습니다. 탭만 닫으면 프로그램은 뒤에서 계속 실행됩니다. 이미 탭을 닫았다면 시작 메뉴에서 Challenge Master를 다시 열어 **앱 종료**를 누릅니다.

## 6. PDF 추출 검토 표시

**PDF 추출 검토**에는 쪽 번호와 상태만 표시되며 추출한 글은 화면에 나오지 않습니다. 모든 쪽에 `원본 대조 필요`가 붙으며, 이 판에는 대조 완료를 표시하는 기능이 없으므로 그대로 두면 됩니다. 스캔한 PDF(글자를 선택할 수 없는 PDF)의 쪽도 `추출 초안`으로 표시되지만 실제로는 글이 추출되지 않습니다.

## 7. 기록이 저장되는 곳

학습 기록, PDF 사본, 추출한 글은 `%LOCALAPPDATA%\ChallengeMaster` 폴더에 저장됩니다. 파일 탐색기 주소창에 이 경로를 그대로 붙여 넣으면 열립니다. 이 파일들은 **암호화되지 않은 상태**로 저장됩니다. PC를 다른 사람과 함께 쓰거나 폴더를 복사해 보낼 때는 이 점에 주의하십시오.

## 8. 제거

1. 먼저 5절 4항에 따라 **앱 종료**를 누릅니다. 프로그램이 실행 중이면 제거가 진행되지 않고 종료 안내가 나타납니다.
2. 시작 메뉴의 `Challenge Master` 폴더에서 **제거**를 엽니다. Windows `설정` → `앱` → `설치된 앱`에서 Challenge Master를 찾아 제거할 수도 있습니다(메뉴 이름 `확인 필요`).
3. 첫 화면에서 `다음`을 누르면 **개인 학습 기록·PDF 사본도 삭제** 칸이 나옵니다. 이어서 `제거` → `닫기` 순서로 진행합니다(단추 이름 `확인 필요`).
   - **선택하지 않으면**(기본값) 프로그램만 지워지고 기록은 남습니다. 같은 Windows 계정에 다시 설치하면 남은 기록을 불러옵니다(제거 후 재설치 시험 전).
   - **선택하면** 7절의 폴더가 통째로 삭제되며 되돌릴 수 없습니다. 처음 고른 원본 PDF 파일은 삭제되지 않습니다.

## 9. 문제가 생겼을 때

프로그램이 열리지 않으면 `%LOCALAPPDATA%\ChallengeMaster\startup-error.log` 파일이 생겼는지 확인합니다. 이 파일에는 오류 시각과 오류 문장이 기록되며, 오류 문장에 Windows 계정 이름이 든 폴더 경로가 포함될 수 있습니다. 내용을 직접 확인한 뒤 운영자에게 보내 주십시오. 파일이 없으면 없다는 사실과 화면 캡처를 보내 주십시오. 설치나 제거 중에 멈추면 그 화면을 캡처해 보내 주십시오.
