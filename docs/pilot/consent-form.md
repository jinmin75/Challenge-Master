# Challenge Master 시범 사용 참여 동의서 (초안)

> [!note] 초안
> 제품 시범 사용을 위한 동의서 초안입니다. 운영자 연락처와 기간은 공개 저장소의 이 파일이 아니라 저장소 밖 사본에만 채웁니다. 결과를 논문·학술 발표에 사용할 경우에는 소속 기관 생명윤리위원회(IRB)의 심의 대상인지 먼저 확인해야 하며, 그 경우 이 문서는 IRB 양식으로 대체됩니다.

## 1. 시범 사용의 목적

Challenge Master는 임용시험을 준비하는 학생이 직접 적은 공부 범위와 공부 시간으로 학습 계획을 세우도록 돕는 Windows 프로그램입니다. 이번 시범 사용은 설치부터 제거까지 프로그램을 쓰면서 **어디서 불편하거나 막히는지**를 찾기 위한 것입니다. 참여자의 학습 능력이나 성적은 평가하지 않습니다.

## 2. 참여 내용

- 기간: 약 1주
- 참여 전 확인: PC의 스마트 앱 컨트롤 설정 상태를 확인합니다. 이 설정 상태에 따라 참여가 어려울 수 있으며, 설정을 바꾸도록 요구하지 않습니다.
- 첫 사용: 설치와 첫 설정을 30~40분 동안 진행하며, 운영자가 옆에서 또는 화면 공유로 지켜봅니다. 화면 공유는 녹화하지 않습니다.
- 혼자 사용: 이후 며칠 동안 평소 공부에 맞춰 프로그램을 사용합니다. 사용 빈도는 참여자가 정합니다.
- 마무리 면담: 20~30분 동안 사용 경험을 묻는 질문에 답합니다.

## 3. 수집하는 정보와 수집하지 않는 정보

운영자가 기록하는 정보는 설치·사용 중 막힌 지점, 도움을 요청한 내용, 소요 시간, 오류 메시지, 면담 답변, 그리고 참여자가 직접 보낸 화면 캡처와 오류 로그입니다. 기록에는 이름 대신 참여자 번호(P1·P2·P3)를 씁니다.

PDF 내용, 교재 원문, 답안, 학습 기록 파일은 수집하지 않습니다. 이 자료들은 참여자 PC의 `%LOCALAPPDATA%\ChallengeMaster` 폴더에만 저장되며, 프로그램은 이를 외부로 보내지 않습니다. 화면 캡처와 오류 로그를 운영자에게 보낼지는 참여자가 내용을 확인한 뒤 결정합니다. 오류 로그에는 Windows 계정 이름이 든 폴더 경로가 포함될 수 있습니다.

## 4. 알아 두어야 할 위험

- 시범판은 코드 서명이 없어 설치할 때 Windows 경고가 나타날 수 있습니다. 보안 설정 변경은 요구하지 않습니다.
- 학습 기록은 암호화되지 않은 상태로 참여자 PC에 저장됩니다.
- 시범판에는 확인되지 않은 오류가 있을 수 있습니다. 중요한 공부 계획을 이 프로그램에만 의존하지 마십시오.
- 제거할 때 **개인 학습 기록·PDF 사본도 삭제**를 선택하면 기록이 되돌릴 수 없게 삭제됩니다.

## 5. 참여자의 권리

참여는 자발적입니다. 언제든 이유를 밝히지 않고 그만둘 수 있으며, 그만두어도 불이익이 없습니다. 그만두면 그때까지 기록된 관찰 메모와 보낸 자료의 삭제를 요청할 수 있습니다. 관찰 메모는 식별 정보를 뺀 요약으로만 프로그램 개선에 사용합니다. 원본 메모와 보낸 자료는 시범이 끝난 뒤 `운영자 기입`일 안에 삭제합니다. 이미 작성된 식별 정보 없는 요약은 참여를 그만둔 뒤에도 남을 수 있습니다.
