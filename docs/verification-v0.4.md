## 남은 검증

- Node.js·Python이 없는 깨끗한 Windows PC에서 설치·첫 실행·반입·제거: **NOT RUN**.
- 코드 서명: **없음**. 일반 학생 배포 전에 서명과 배포 경로를 정해야 한다.
- 제거 시 개인 기록을 삭제할지 선택하는 화면: **미구현**. 현재 제거기는 기록을 항상 보존한다.
- 스캔 OCR, 복잡한 표·수식, 실제 교재의 페이지 충실도, 학생 사용성, LLM 계정 연결·학습효과: **NOT RUN**.

K01–K25의 제품 전체 시나리오 통과를 이 기록으로 주장하지 않는다. L13은 현재 개발 PC의 시험 설치 범위만 통과했다.
