## 다음 검증 범위

Node.js·Python이 없는 깨끗한 Windows 환경에서 설치·첫 실행·PDF 반입·재시작·제거를 반복한다. 코드 서명과 배포 경로도 정해야 한다. 이어서 스캔 OCR과 복잡한 페이지의 충실도 검증, 공식 계정 연결, 실제 학생 사용성 검증을 진행한다.

‘개발 완료’나 임의의 완성도 점수를 현재 상태로 표기하지 않는다.
