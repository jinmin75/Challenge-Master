## 시범 전에 남은 일

1. Windows 샌드박스를 켜고 `npm run test:sandbox`를 통과시킨다(L16).
2. 설치파일을 드라이브 공유 폴더에 올리고, 운영자 PC에서 그 링크로 내려받아 설치·제거하며 경고 화면과 제거 화면을 캡처한다. 이 캡처로 학생 설치 안내의 `확인 필요` 문구를 확정한다.
3. 링크를 보내기 전에 각 학생 PC의 스마트 앱 컨트롤 상태를 확인한다.

‘개발 완료’나 임의의 완성도 점수를 현재 상태로 표기하지 않는다.
