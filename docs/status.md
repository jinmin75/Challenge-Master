## 바로 다음 구현 범위

공식 계정 연결 경로 한 개의 가능 범위를 확인하고, 합성 PDF의 지정 범위에서 변환·출처 추적을 시험한다. 외부 모델이 없어도 검증할 수 있는 시간 예산·중복 방지·버전 충돌부터 구현한다. 실제 학생 자료 사용은 해당 자료의 이용 권한과 처리 동의를 확인한 뒤 진행한다.

‘개발 완료’나 ‘9.8점’을 현재 상태로 표기하지 않는다.
