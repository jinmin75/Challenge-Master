## v0.7 대비 변경

- **요청 규칙 분리**: 서버(`src/web.mjs`)에 있던 계획 시작·기록·쉬기·건너뛰기·캘린더 요청 규칙을 저장 방식과 떼어 `src/app-core.mjs`로 옮겼다. PDF 쪽 읽기는 `src/pdf-read.mjs`, 초안 만들기는 `src/pdf-core.mjs`로 옮겼다. 설치판과 웹 버전이 같은 규칙 코드를 쓴다. 분리 뒤에도 설치판 시험 109개가 그대로 통과했다.
- **웹 버전 저장**(`web/local-api.js`): 자료 설정·계획·공부 기록·추출 글자를 브라우저 IndexedDB에만 저장한다. 쓰기는 한 트랜잭션 안에서 기록을 다시 읽고 `applyEvent`로 검사한 뒤 더한다. 다른 탭에서 자료를 바꿨으면 쓰기를 거부한다. 첫 등록과 불러오기 때 영구 저장(`navigator.storage.persist()`)을 요청한다. PDF 원본은 저장하지 않는다(D022).
- **브라우저 PDF 추출**: 같은 pdf.js(legacy 빌드)를 사이트에 함께 올리고 같은 `readPdfPages`로 읽는다. 원본의 SHA-256은 Web Crypto로 계산한다. 50MB 초과는 거부한다.
- **화면**: 웹 버전에서는 「앱 종료」를 숨기고 「내 기록 관리」(백업 파일 저장·불러오기·이 브라우저의 기록 지우기)를 보인다. 백업을 한 번도 하지 않았거나 마지막 백업 뒤 7일이 지나면 맨 위에 안내를 띄운다. 다른 탭의 기록 변경을 BroadcastChannel로 받아 다시 그린다. 스크립트·스타일 경로를 상대 경로로 바꿔 하위 경로(`/Challenge-Master/`)에서도 열린다.
- **보안 정책**: 빌드된 `index.html`에 CSP를 넣었다(`default-src 'self'`, `connect-src 'self'`, `script-src 'self' 'wasm-unsafe-eval'` 등). pdf.js의 코드 평가는 끈다(`isEvalSupported: false`).
- **배포 게이트**: `pages` 워크플로는 단위 시험과 Chrome·WebKit 학생 흐름 시험이 통과한 파일만 배포한다.
- 이 PC의 구글 드라이브 폴더에서 Node 25의 재귀 복사(`fs.cpSync` recursive)가 오류 메시지 없이 종료 코드 127로 끝났다. 빌드 스크립트는 파일을 하나씩 복사한다.

웹 버전 학생 흐름 시험(`scripts/browser-web.mjs`)이 확인하는 것:

1. 데모 입력에서 지난 날 확인 전체(사후 기록, 누락 확인+보완, 한도 초과 보완의 오류와 미저장, 휴식, 확인 목록 비움, 달 이동, 오늘 기록의 캘린더 반영). 기록은 페이지의 같은 모듈로 넣고 읽는다
2. 새 브라우저 프로필에서 한글(ToUnicode) PDF 2쪽 등록: 1쪽 「추출 초안」, 2쪽 「글자 없음」, 저장된 초안에 한글이 남음
3. 오늘 시작·5분 기록 뒤 새로고침해도 기록 유지
4. 백업 안내 표시 → 백업 파일 다운로드(설정·기록·초안 포함) → 안내 사라짐
5. 두 번째 탭에서 5분 기록 → 첫 탭이 새로고침 없이 10분 표시
6. 기록 지우기 → 데모로 돌아감, 잘못된 파일 불러오기 거부, 백업 파일 불러오기 → 5분 기록과 자료 이름 복원, 마지막 백업 날짜 표시
7. 390px 폭에서 가로 스크롤 없음
8. 콘솔 오류 0, 실패 요청 0, **사이트 밖으로 나간 요청 0**

큰 PDF 측정의 그림은 압축하지 않은 단색이다. 실제 교재 PDF는 압축된 그림과 글꼴이 많아 시간이 다를 수 있다. 측정은 이 PC 한 대에서 한 번씩만 했다.

## 남은 검증

- 실제 Safari(macOS·iOS), Edge, Firefox, 휴대폰·태블릿: **NOT RUN**. WebKit 시험은 Playwright의 WebKit 빌드로 했으며 Safari 자체가 아니다.
- 영구 저장 요청의 실제 결과: 시험 환경의 헤드리스 Chrome과 WebKit은 거절했다(화면에 「오래 쓰지 않은 사이트의 기록을 정리할 수 있습니다」 표시). 학생 브라우저에서 허락되는지는 **NOT RUN**.
- 브라우저가 실제로 데이터를 정리하는 조건과 시점: 문서 확인뿐이며 재현 **NOT RUN**.
- 여러 달 사용, 실제 교재 PDF, 학생 사용성: **NOT RUN**.
- 설치판(0.7.0)은 이번 변경 뒤 다시 빌드하지 않았다. 예비로 남은 설치판을 다시 배포하려면 설치본 시험부터 다시 한다.

K01–K25의 제품 전체 시나리오 통과를 이 기록으로 주장하지 않는다.
