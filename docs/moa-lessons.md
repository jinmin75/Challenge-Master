# 모아(학습자료 대시보드)의 실패 지점과 이번 설계의 대응

작성일 `2026-09-29`. 근거 결정은 [D023](decisions.md)이다. 학습 기능(복기·오답노트·AI 연결·Wiki 내보내기)은 기존 로컬 앱 「모아」 v2.7의 설계를 따르되, 모아에서 실제로 실패한 지점을 되풀이하지 않는다. 사용자 지시: 「모아 실패 지점을 잊지 말아야 한다」. 이 문서는 학습 기능의 각 단계를 마칠 때 점검표로 쓴다.

근거는 모아 저장소의 원문이다: 검증 기록(`docs/검증_기록.md` v2.7.1 절, 수업일 `2026-09-16` 저녁), 학부 6강 학생 실습가이드 6-09, 강의 작업 기록(`_작업이어가기.md`), `WikiIngest.ps1`·`StudyStore.ps1` 코드. 아래 판단 가운데 원인 추정은 그렇게 표시했다.

## 모아에서 그대로 가져오는 것

- (D024로 바뀜) 학습실은 한 화면(문제·내 답 → 교재랑 맞춰 보기 → 고쳐 쓰기)으로 줄이고, 「다시 풀기」와 내 답 고정 규칙만 가져온다
- (D024로 바뀜) 학습로그 유형·확인 상태는 화면에서 빼고 메모 한 칸으로. AI가 제안한 메모는 학생이 넣기 전에는 Wiki에 넣지 않음
- (D024로 바뀜) 오답 원인은 학생 말 4가지로 고르고, 임용 볼트 7분류(`04_오답과_주간복습.md`)는 내보낼 때 대응
- Wiki 출처 노트 형식: `wiki/자료원본/<제목>-<id8>-<rev8>.md`, `status: "needs_review"`, `verification_status: "user_source"`, 원자료는 `raw/` 아래 판별 폴더
- 복습일은 학생이 직접 고른다(`2026-09-29` 사용자 결정). 자동 간격 계산은 하지 않는다
